# Desidratador - Robótica Roosevelt

Código Arduino de um desidratador com hotend 24 V acionado por relé.

## Componentes

- Arduino Uno ou Nano
- DHT11 para temperatura e umidade da câmara
- NTC 100k 3950 para temperatura do bloco do hotend
- OLED SSD1306 128x64 I2C
- Módulo relé
